# দারুননাজাত মাদ্রাসা — প্রিমিয়াম ভর্তি পোস্টার ডিজাইন স্টুডিও (Darunnajat Madrasah Poster Studio)

দারুননাজাত মাদ্রাসার ২০২৬-২৭ শিক্ষাবর্ষের ভর্তি কার্যক্রমের জন্য তৈরি একটি প্রিমিয়াম, রাজকীয় ও আধুনিক পোস্টার ডিজাইন এবং মাল্টি-ফরম্যাট এক্সপোর্ট অ্যাপ্লিকেশন।

## 🕌 পোস্টারের মূল তথ্য (Poster Information)

- **মাদ্রাসা:** দারুননাজাত মাদ্রাসা
- **ভর্তি কার্যক্রম:** ভর্তি চলছে
- **ভর্তি শুরু:** ১ ডিসেম্বর ২০২৬
- **আমাদের বৈশিষ্ট্যসমূহঃ**
  1. কঠিন তদারকি করা হয়
  2. আখলাকি মানুষ বানানো হয়
  3. বেত্রাঘাত করা হয় না।
  4. তিনবেলা ভালো মানের খানা প্রদান করা
  5. আন্তর্জাতিক মানে শিক্ষা প্রদান
  6. প্রশিক্ষণপ্রাপ্ত শিক্ষক প্যানেল
  7. মাথায় নষ্ট মামা কাজ করবার
- **স্থানঃ** দারুননাজাত মাদ্রাসার পাশেই, সারুলিয়া, ডেমরা ঢাকা
- **যোগাযোগঃ** ০১৭৭৬২৮৯৮০১, ০১৬৮৫৩৬০৯৮১

## 🛠️ ব্যবহৃত প্রযুক্তিসমূহ (Technology Stack)

- **React + TypeScript:** মূল অ্যাপ্লিকেশন শেল, টাইপ-সেফ আর্কিটেকচার ও স্টেট ম্যানেজমেন্ট
- **SVG.js (`@svgdotjs/svg.js`):** গাণিতিক প্যারামেট্রিক ভেক্টর ডিজাইন, ইসলামিক মেহরাব খিলান ও গিরিহ স্টার প্যাটার্ন জেনারেটর
- **Fabric.js (`fabric`):** সম্পূর্ণ ইন্টারেক্টিভ ক্যানভাস এডিটর — টেক্সট ড্র্যাগ, স্কেল, রোটেট ও সরাসরি ইনলাইন এডিটিং
- **HTML/CSS + Tailwind CSS v4:** নিখুঁত টাইপোগ্রাফি, রাজকীয় গোল্ড ফয়েল গ্রেডিয়েন্ট ও গ্লাস-মরফিজম লেআউট
- **Google Fonts & Local Bundled Fonts:** Noto Serif Bengali, Hind Siliguri, Noto Sans Bengali ও Tiro Bangla
- **Sharp:** ৩০০০+ পিক্সেল ও ৩০০ DPI ক্রিস্টাল ক্লিয়ার প্রিন্ট-রেডি ইমেজ প্রসেসিং ও কনভার্সন ব্যাকএন্ড
- **Export Formats:**
  - 🖼️ **Ultra HD PNG (300 DPI):** Sharp ব্যাকএন্ড দ্বারা প্রসেসকৃত নিখুঁত প্রিন্ট কোয়ালিটি
  - 📐 **Vector SVG:** অসীম রেজোলিউশন স্কেলেবল ভেক্টর ফাইল
  - 📄 **Print-Ready PDF:** A4 সাইজের প্রিন্ট-উপযোগী PDF (jsPDF)
  - 🖨️ **Direct Print:** ব্রাউজার প্রিন্ট ডায়লগ মার্জিনহীন A4 ফরম্যাটে

## 🚀 রান করার নিয়ম (Running the Project)

```bash
# ডিপেনডেন্সি ইনস্টল
npm install

# ডেভেলপমেন্ট সার্ভার চালু
npm run dev

# প্রোডাকশন বিল্ড
npm run build
```
